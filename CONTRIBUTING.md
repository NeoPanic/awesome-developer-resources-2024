# Contributing to Awesome Developer Resources

Thank you for considering contributing to **Awesome Developer Resources**! We welcome all contributions that help developers discover high-quality tools, libraries, frameworks, and resources.

## 📜 Rules for Submissions

1. **Relevance**: Resources should be actively maintained, useful to developers, and of high quality.
2. **Format**: Follow the existing table formatting in `README.md`:
   `| [Name](URL) | Category / Type | Brief description ending with a period. |`
3. **Alphabetical Order**: Place new additions in alphabetical order within their respective category section.
4. **No Spam**: Self-promotional spam or low-quality tools will be rejected.
5. **Clean Links**: Direct links only (no affiliate codes or tracking links).

## 🚀 How to Submit a Pull Request

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/awesome-developer-resources-2024.git
   ```
3. **Create a new branch** for your feature or addition:
   ```bash
   git checkout -b add-resource-name
   ```
4. **Make your changes** in `README.md`.
5. **Commit your changes**:
   ```bash
   git commit -m "add: Add Resource Name to AI Frameworks section"
   ```
6. **Push to your fork**:
   ```bash
   git push origin add-resource-name
   ```
7. **Open a Pull Request** against the `main` branch.

Thank you for your contribution! ⭐
